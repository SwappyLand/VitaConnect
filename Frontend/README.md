
# MediConnect – Practo-like Doctor Consultation App

## Setup
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Roles
- Patient: Book doctor appointments
- Doctor: Register & wait for approval
- Admin: Approve doctors (password: admin123)

## Notes
- CSV-based storage
- Pune, Maharashtra doctors only
- Video call, Supabase, and Google Calendar hooks can be added later
